# Lib_math

**High-performance linear algebra library providing SIMD-accelerated, memory-aligned vector and matrix primitives.**

- 100+ optimized functions intended for graphics projects in C
- Features compiler vector extensions and explicit SSE intrinsics, built around a 128-bit register wrapper

Heavily used in my [Path Tracer](https://github.com/mordori/miniRT)
